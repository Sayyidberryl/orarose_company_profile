# ORAROSE Company Profile

Website profil perusahaan resmi ORAROSE.

## Tech Stack
- React
- Vite

## Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Jalankan development server:
   ```bash
   npm run dev
   ```

3. Build untuk produksi:
   ```bash
   npm run build
   ```
